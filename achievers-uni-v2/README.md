# Achievers University Website & Portal (Demo)

Classic, fully responsive multi-page university website.
**No Node.js / npm required** — works by opening the files or using any static server.

## How to run

### Option 1 – Double-click
Open `index.html` in your browser (Chrome / Edge recommended).

### Option 2 – VS Code Live Server
Right-click `index.html` → Open with Live Server.

### Option 3 – Simple local server
```bash
# Python
python -m http.server 8080

# or Node
npx serve .
```
Then open http://localhost:8080

- Fully responsive (mobile, tablet, desktop)
